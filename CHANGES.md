# Antigravity 2.0 Android — v0.2.0

## Что сделано
- **Сборка и подпись.** Debug и release подписываются одним ключом, пакет один (без `.debug`), поэтому APK ставятся поверх друг друга. `versionCode` растёт от номера запуска CI. Без секретов CI падает с понятной ошибкой вместо случайного ключа на каждый запуск.
- **Запуск.** Фоновые сервисы больше не стартуют безусловно. Remote Control поднимается только если включён в настройках. Тема до первого кадра задана в `themes.xml`, белой вспышки нет.
- **Вход по API-ключу.** При первом запуске экран входа: ввод ключа, проверка запросом к Gemini API (`x-goog-api-key`), сохранение в `EncryptedSharedPreferences`. Ключ не попадает в `settings.json`.
- **Оффлайн.** Оффлайн-режим (LiteRT/GGUF) удалён полностью, вместе с зависимостями mediapipe и vosk. Без сети приложение показывает баннер, отправка блокируется с понятным текстом, а список и история чатов открываются с диска.
- **Unlocker удалён.** Модуль, который переписывал ответы Google, удалён из проекта, в том числе из манифеста и из запросов к моделям.
- **Честный ответ при сбое.** Вместо фразы «Задача выполнена» при ошибке модели показывается сама ошибка.
- **Remote Control (Beta).** По умолчанию выключено. Переключатель в настройках, метка BETA, миграция старых `settings.json` (выключит один раз).
- **Интерфейс.** Новый главный экран на Material 3: чат, терминал, Remote (Beta), инструменты (лимиты, MCP, расписание), настройки. Стеклянные карточки, иконки Material.
- **Иконка.** Новая метка «A» с градиентом, адаптивный слой в безопасной зоне.

## Что не сделано
- **Анимации: 26 из 59 подключены к экранам.** Остальные 33 описаны в `AgMotion.kt` (`AgAnim`), но не привязаны к UI. Их нужно подключить по одной.
- **Вход через Google.** Кнопка есть, но неактивна. Нужен OAuth Web client ID из Google Cloud и настройка Credential Manager.
- **Remote Control.** Мост к antigravity.google.com не реализован. Вкладка честно говорит, что мост не подключён.
- **Компиляция не проверена.** В среде сборки не было Android SDK и kotlinc. Проверены импорты, отсутствие хвостов от удалённого кода и баланс скобок. Перед использованием соберите проект.
- **Аккаунты.** Экран переключения Google-аккаунтов убран, так как OAuth в этой версии не работает.
- **Разрешения.** В манифесте остаются SEND_SMS, CALL_PHONE, READ_CONTACTS (для phone-control). Их стоит убрать, если функция не нужна.

## Сборка без ключа в GitHub (рекомендуется)
1. Ключ один раз на своём компьютере: `./scripts/make_keystore.sh` → `antigravity.jks`. В git не коммитить.
2. `git push` в `main`. CI соберёт неподписанный `app-release-unsigned.apk` и выложит его как артефакт. Ключа в GitHub нет, в логах его нет.
3. Скачайте артефакт и подпишите локально: `ANDROID_HOME=... ./scripts/sign_local.sh app-release-unsigned.apk antigravity.jks`. Получится `app-release-signed.apk`.
4. Установите подписанный APK. Все следующие версии подписывайте тем же ключом, тогда обновления ставятся поверх.

## Сборка с подписью в CI (по желанию)
Если добавить секреты `AG_KEYSTORE_B64`, `AG_KEYSTORE_PASSWORD`, `AG_KEY_ALIAS`, `AG_KEY_PASSWORD`, CI подпишет APK сам. Тогда ключ будет лежать в GitHub Secrets, и любой, кто получит доступ к настройкам репозитория, сможет его использовать.
